SIMOON AI — Quick Start
=======================

HOW TO OPEN
1. Extract the SIMOON-AI.zip file.
2. Open the extracted SIMOON-AI folder.
3. Double-click index.html to open the website in your browser.

OPTIONAL: OPEN IN VS CODE
1. Open VS Code.
2. Choose File > Open Folder.
3. Select the extracted SIMOON-AI folder.
4. Open index.html and use Live Server if installed.

FILES
- index.html: website structure
- style.css: design and responsive layout
- script.js: search, category filters, and theme switch

NOTES
- Internet is needed for Google Fonts and opening the listed AI tools.
- This is an AI tools directory, not an AI model itself. Real AI generation/chat features require an AI API.
